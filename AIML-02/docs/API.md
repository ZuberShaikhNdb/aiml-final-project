# API reference
Interactive docs: http://localhost:8000/docs (Swagger UI, generated by FastAPI).

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Liveness and whether demo mode is on |
| GET | `/config` | Disclaimer text and demo flag |
| GET | `/studies` | All studies, newest first, with AI result and review status |
| GET | `/studies/{id}` | One study |
| GET | `/studies/{id}/image/{preview\|overlay}` | PNG of the scan or the scan with the AI overlay |
| POST | `/studies/{id}/review` | Body `{"decision":"approved\|rejected","reviewer":"name","comment":""}`. Appends to the audit log |
| POST | `/studies/{id}/reprocess` | Re-run inference on a study already in Orthanc |
| GET | `/audit` | Audit entries, newest first |
| GET | `/audit/verify` | Recomputes the hash chain: `{"ok":true,"checked":N,"broken_at":null}` |
| POST | `/upload` | Multipart `files`: forwards DICOM files to Orthanc |

## Study object
```json
{
  "orthanc_id": "...", "modality": "DX", "kind": "classification",
  "top_label": "Effusion", "confidence": 0.41, "model_version": "densenet121-1a2b3c4d",
  "status": "pending",
  "details": {"predictions": {"Effusion": 0.41, "...": 0.0}, "heatmap_for": "Effusion"}
}
```
For `kind: "segmentation"`, `details` holds `voxels`, `volume_ml`, `slice_index`, `n_slices`.

## Data
- Orthanc stores DICOM in the `orthanc-db` volume.
- The backend stores results, images and the audit log in the `backend-data` volume (`/data`).
- Training data is not in git. It is versioned with DVC (`dvc.yaml`).
